# Getting started

You can translate your first file in a few minutes. Here is the whole path.

1. **[Install](installation.md) Babel Fishers.** It is a Python package.
2. **[Create a project](quickstart.md#1-create-the-project).** One command writes the configuration file.
3. **[Set your provider key](quickstart.md#2-set-your-provider-key).** Keys are read from environment variables.
4. **[List your files](quickstart.md#3-list-the-files-to-translate).** Tell Babel Fishers what to translate.
5. **[Translate](quickstart.md#4-preview-then-translate).** Preview first. Then run it for real.

## What you need

- Python 3.11 or newer.
- Source files in one of the [supported formats](../formats.md).
- An account with one [translation provider](../guides/providers.md).

## Where to go next

After the quickstart, these pages help most.

- [Configuration](../guides/configuration.md) explains every option in `babelfishers.toml`.
