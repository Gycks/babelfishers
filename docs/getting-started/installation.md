# Installation

Babel Fishers is published as a Python package and can be installed with pip, ideally by using a virtual environment. It needs Python 3.11 or newer.

## Install

=== "pipx"

    Use `pipx` to install it as a standalone command.

    ```bash
    pipx install babelfishers
    ```

=== "pip"

    Use `pip` inside a virtual environment.

    ```bash
    pip install babelfishers
    ```

=== "uv"

    Add it to a project as a dependency.

    ```bash
    uv add babelfishers
    ```


## Check the install

Print the version.

```bash
babelfishers --version
```

List the available commands.

```bash
babelfishers --help
```
