# Guides

These pages show you how to do specific tasks. You can read them in any order. If you are new, start with the [Quickstart](../getting-started/quickstart.md).

## Set up your project

- [Configuration](configuration.md). Describe your languages, files and options in `babelfishers.toml`.
- [Translation providers](providers.md). Choose a provider and set its credentials.
- [Continuous integration](ci.md). Run translations in your pipeline and receive them as a pull request.

## Control the result

- [Glossaries](glossaries.md). Keep terms unchanged, fix their translations or add context.
- [Placeholders and protected content](placeholders.md). See how variables and markup survive translation.
- [Translation memory](translation-memory.md). Reuse earlier translations and clear them when needed.

## Get help

- [Troubleshooting](troubleshooting.md). Find the cause of common errors and warnings.
