# Supported locales

Babel Fishers supports 27 languages. Use these codes in the `[locale]` section of `babelfishers.toml`.

To list them in your terminal, run `babelfishers locales`. To filter by code or name, use `--search`.

```bash
babelfishers locales --search fr
```

| Code | Language | Code | Language | Code | Language |
|---|---|---|---|---|---|
| `ar` | Arabic | `fr` | French | `pt` | Portuguese |
| `bg` | Bulgarian | `hu` | Hungarian | `ro` | Romanian |
| `cs` | Czech | `id` | Indonesian | `ru` | Russian |
| `da` | Danish | `it` | Italian | `sk` | Slovak |

| `en` | English | `nl` | Dutch | `uk` | Ukrainian |
| `es` | Spanish | `no` | Norwegian | `vi` | Vietnamese |
